Syntax & rules cheat sheet

For C, the "formulas" are the rules and patterns these papers kept testing.

Number systems

Unsigned: value = Σ bᵢ · 2ⁱ
1010 0111 = 128 + 32 + 4 + 2 + 1 = 167.
Sign-bit (sign-magnitude): first bit is the sign, the rest is the size
1 means negative. 1010 0111 → −39. −43 → 1010 1011.
2's complement: invert every bit, then add 1
In 8 bits, the value is −128 × (first bit) + the rest. 1110 1001 → −23. −43 → 1101 0101. −99 → 1001 1101.
Minimum bits
n bits hold 0 to 2ⁿ − 1 unsigned. A signed number needs one more bit for the sign: +91 = 1011011 is 7 bits (8 with a sign bit); −69 needs 8 bits in both sign-bit and 2's complement.

Arrays & strings

&A[i][j] = base + (i × COLUMNS + j) × sizeof(type)
Row-major order. B[3][4] in int B[5][6] at 2000 → 2000 + (3 × 6 + 4) × 4 = 2088.
sizeof counts the '\0'; strlen doesn't
char A[] = "H": sizeof(A) = 2, strlen(A) = 1. In C, a character constant like 'H' is an int, so sizeof('H') = 4. The program prints 4 2 1.
'7' − '0' = 7,   7 + '0' = '7'
Converts between a digit character and its number — used in the string-addition program.
'a' − 'A' = 32
Add or subtract 32 to flip case, or use toupper() / tolower() from <ctype.h>.
Rotate right by k: out[(i + k) % n] = a[i]
1 2 3 4 5 rotated by 2 gives 4 5 1 2 3.
char words[ROWS][LONGEST + 1]
Leave room for '\0': "ELEPHANT" has 8 letters, so each row needs at least 9.

Control flow

continue → next iteration; break → leave the loop or switch; return 0 → leave main()
If continue comes before i++, i never changes and the loop runs forever.
do { … } while (condition);
The body always runs at least once. Note the semicolon after the condition.
switch (x) { case 1: …; break; default: …; }
Without break, execution falls through into the next case.
result = (condition) ? value1 : value2;
The ternary operator — a one-line if-else that produces a value.

Operators & types

int / int truncates: 7 / 2 = 3,   (float)7 / 2 = 3.5
Cast before dividing. With a = 7, b = 2: a/b + (float)a/b + a/(float)b = 3 + 3.5 + 3.5 = 10.00. Casting all three terms gives 10.50.
float: 4 bytes, ~6–7 digits · double: 8 bytes, ~15–16 digits
printf uses %f for both; scanf needs %f for float and %lf for double.
scanf("%d", &num);
Normal variables need &. A char array read with %s does not.

Algorithms & flowcharts

Binary search: mid = low + (high − low) / 2
The array must already be sorted.
Bubble sort: n − 1 passes; after pass p the p largest are in place
[44, 33, 55, 22, 11] → [33, 44, 22, 11, 55] → [33, 22, 11, 44, 55] → [22, 11, 33, 44, 55] → [11, 22, 33, 44, 55].
HCF (Euclid): while (b != 0) { t = b; b = a % b; a = t; } → answer is a
hcf(6, 8) = 2.
Flowchart symbols
Oval: start/stop · Parallelogram: input/output · Rectangle: process · Diamond: decision · Arrows: flow, including loops back.

Common mistakes that lose marks

Specific traps these five papers set — each one costs easy marks.

✕
Missing & in scanfscanf("%d", factorial) should be scanf("%d", &num). Oct 2024
✕
Using a variable before it has a valueint num, factorial = num; copies garbage — and a factorial must start at 1. Oct 2024
✕
Commas instead of semicolons in a for loopfor (i = 1, i <= num, ++i) must use semicolons. Oct 2024
✕
printf without a format specifierprintf("Factorial = n!", factorial) never prints the value — it needs %d. Oct 2024
✕
continue before the incrementThe loop never reaches i++, so it prints "Before continue: i = 0" forever — it's an infinite loop, and "Loop exited" never prints. Mar 2025
✕
sizeof vs strlensizeof(A) includes '\0'; strlen(A) doesn't. And sizeof('H') is 4 in C, not 1. Mar 2025
✕
Integer division before the cast7 / 2 is 3, not 3.5, so the Mar 2026 expression gives 10.00. Doing each division in float — for example casting every term — gives 10.50. Mar 2026
✕
Tracing with the original array valuesIn a[i] = a[i] + a[4 − i], a[1] and a[0] have already changed by the time i = 3 and 4. The output is 6 6 6 10 11, not 6 6 6 6 6. Oct 2025
✕
Assuming the array changesa[i] = a[a[i]/2 − 1] on {2, 4, 6, 8, 10} copies each element onto itself — the output is 2 4 6 8 10. Trace, don't guess. Oct 2025
✕
Multiplying by rows instead of columnsRow-major address uses i × (number of columns). Oct 2025
✕
Mixing sign-bit and 2's complement−43 is 1010 1011 in sign-bit but 1101 0101 in 2's complement. Oct 2024, Mar 2025
✕
No room for '\0'The second size of the 2-D char array must fit the longest word plus 1 — 9 for ELEPHANT. Mar 2026
✕
Forgetting break in switchWithout it, the calculator runs every case below the matching one. Mar 2024, Mar 2026
✕
Rewriting everything when asked for lessPapers explicitly asked for corrections by line number only, and blanks in order — and warned there's no partial credit for messy answers. Oct 2024, Mar 2025, Oct 2025, Mar 2026

If you only have one evening

  1. Number conversions — unsigned, sign-bit, 2's complement, and minimum bits. In every paper.
  2. Predict-the-output practice — loops with continue/break, arrays changed inside a loop, sizeof vs strlen, integer division and casting. Trace each line on paper.
  3. Flowcharts — the symbols, plus bubble sort, HCF, and a condition-based calculation.
  4. Strings — loop until '\0', case flipping, and 2-D character arrays.
  5. Arrays — row-major address, rotation, and 2-D insertion.
  6. Theory — the standard differences list, life cycle of a C program, and do-while / switch syntax.

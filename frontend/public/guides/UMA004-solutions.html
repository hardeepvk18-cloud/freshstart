1 (a)2 marksReduction of order
If y₁(x) = x + 1 is one solution of (x² + 2x − 1)y″ − 2(1 + x)y′ − 2y = 0, find the other solution.
The paper has a misprint here

Put y = x + 1 into the equation exactly as printed and you get −4(x + 1), not 0. So x + 1 is not a solution of what is written. The intended last term is + 2y, and with that the equation becomes identical to 2025 Q1(b) multiplied by −1. Solve the corrected equation and say so in one line — that is what the examiner is looking for.

Step 1 — put it in standard form

(x² + 2x − 1)y″ − 2(1 + x)y′ + 2y = 0 y″ + P(x)y′ + Q(x)y = 0, where −2(1 + x) 2 P(x) = ───────────── , Q(x) = ───────────── (x² + 2x − 1) (x² + 2x − 1)

Step 2 — the reduction-of-order formula

When one solution y₁ is known, the second is y₂ = y₁ ∫ [ e−∫P dx / y₁² ] dx. Everything below is just evaluating that.

∫P dx = ∫ −2(1 + x)/(x² + 2x − 1) dx Let u = x² + 2x − 1, du = (2x + 2)dx = 2(1 + x)dx = −∫ du/u = −ln|u| so e^(−∫P dx) = e^(ln|u|) = x² + 2x − 1

Step 3 — do the integral

e^(−∫P dx) x² + 2x − 1 ∫ ───────────── dx = ∫ ───────────── dx y₁² (x + 1)² Write the numerator as (x + 1)² − 2 : (x + 1)² − 2 ⎡ 2 ⎤ ∫ ────────────── dx = ∫ ⎢ 1 − ────── ⎥ dx (x + 1)² ⎣ (x + 1)²⎦ 2 = x + ─────── (x + 1)

Step 4 — multiply back by y₁

⎡ 2 ⎤ y₂ = (x + 1) ⎢ x + ─────── ⎥ = x(x + 1) + 2 = x² + x + 2 ⎣ (x + 1) ⎦
Answer
y₂ = x² + x + 2 General solution: y = c₁(x + 1) + c₂(x² + x + 2)

Check it yourself: substitute y₂ back — y₂″ = 2, y₂′ = 2x + 1, and (x²+2x−1)(2) − 2(1+x)(2x+1) + 2(x²+x+2) = 0. The Wronskian is x² + 2x − 1, which is not identically zero, so the two solutions are independent.

1 (b)4 marksRLC circuit
A series circuit has E(t) = cos t, an inductor of 0.1 H, a capacitor of 5 F and a resistor of 0.3 Ω. Initial current and charge are both zero. Find the charge on the capacitor for t > 0.

Step 1 — write the circuit equation in charge

For a series RLC circuit, Kirchhoff's voltage law in terms of charge q(t), with i = dq/dt, gives:

d²q dq q L ───── + R ──── + ─── = E(t) dt² dt C 0.1 q″ + 0.3 q′ + q/5 = cos t Multiply throughout by 10: q″ + 3q′ + 2q = 10 cos t, q(0) = 0, q′(0) = 0

Step 2 — complementary function

m² + 3m + 2 = 0 ⟹ (m + 1)(m + 2) = 0 ⟹ m = −1, −2 q_c = c₁e^(−t) + c₂e^(−2t)

Step 3 — particular integral

Try q_p = A cos t + B sin t q_p″ = −A cos t − B sin t q_p′ = −A sin t + B cos t Substitute: (−A + 3B + 2A) cos t + (−B − 3A + 2B) sin t = 10 cos t (A + 3B) cos t + (B − 3A) sin t = 10 cos t Compare: A + 3B = 10 , B − 3A = 0 ⟹ B = 3A A + 9A = 10 ⟹ A = 1, B = 3 q_p = cos t + 3 sin t

Step 4 — apply the initial conditions

q(t) = c₁e^(−t) + c₂e^(−2t) + cos t + 3 sin t q(0) = 0 : c₁ + c₂ + 1 = 0 … (i) q′(t) = −c₁e^(−t) − 2c₂e^(−2t) − sin t + 3 cos t q′(0) = 0 : −c₁ − 2c₂ + 3 = 0 … (ii) From (i): c₁ = −1 − c₂. Put into (ii): 1 + c₂ − 2c₂ + 3 = 0 ⟹ c₂ = 4, c₁ = −5
Answer
q(t) = −5e^(−t) + 4e^(−2t) + cos t + 3 sin t
Where marks go

Two things. First, the initial condition "current is zero" means q′(0) = 0, not q(0) = 0 — you need both, and they are different conditions. Second, clear the decimals by multiplying by 10 straight away; working with 0.1 and 0.3 through four steps is how arithmetic slips in.

1 (c)4 marksCauchy–Euler, operator method
Find the general solution of x²y″ − 3xy′ + 5y = x²(ln³x − 5 ln²x), finding the particular integral by the operator method.

Step 1 — substitute x = ez

This is the standard move for every Cauchy–Euler equation. With z = ln x and D = d/dz:

x y′ = D y x²y″ = D(D − 1) y D(D − 1)y − 3Dy + 5y = e^(2z)(z³ − 5z²) (D² − 4D + 5) y = e^(2z)(z³ − 5z²)

Step 2 — complementary function

m² − 4m + 5 = 0 ⟹ m = 2 ± i y_c = e^(2z)(c₁ cos z + c₂ sin z) = x²(c₁ cos(ln x) + c₂ sin(ln x))

Step 3 — particular integral by the shift rule

Use 1/f(D) · eazV(z) = eaz · 1/f(D + a) · V(z), with a = 2.

1 PI = ───────────────── e^(2z)(z³ − 5z²) D² − 4D + 5 1 = e^(2z) ───────────────────── (z³ − 5z²) (D+2)² − 4(D+2) + 5 (D+2)² − 4(D+2) + 5 = D² + 4D + 4 − 4D − 8 + 5 = D² + 1 1 = e^(2z) ───────── (z³ − 5z²) 1 + D² Expand: (1 + D²)^(−1) = 1 − D² + D⁴ − … D²(z³ − 5z²) = 6z − 10 D⁴(z³ − 5z²) = 0 = e^(2z)[ (z³ − 5z²) − (6z − 10) ] = e^(2z)( z³ − 5z² − 6z + 10 )

Step 4 — go back to x

PI = x²( ln³x − 5 ln²x − 6 ln x + 10 )
Answer
y = x²[ c₁ cos(ln x) + c₂ sin(ln x) + ln³x − 5 ln²x − 6 ln x + 10 ]
Where marks go

The binomial expansion of 1/(1 + D²) must be carried far enough to kill the polynomial, but no further — here D⁴ already gives zero, so two terms are enough. Students often stop at 1 and lose the −6z + 10.

2 (a)4 marksUnit step function
Express f(t) = t² for 0 < t < 1, e−t for t > 1 in terms of the unit step function and hence find its Laplace transform.

Step 1 — write f in unit-step form

The pattern is always: start with the first piece valid everywhere, then switch the difference on at the break point.

f(t) = t² + (e^(−t) − t²) u(t − 1)

Step 2 — the second shifting theorem

L{g(t)u(t − a)} = e−as L{g(t + a)}. Here a = 1, so shift the argument by writing t = τ + 1.

g(t) = e^(−t) − t² g(τ + 1) = e^(−(τ+1)) − (τ + 1)² = e^(−1)e^(−τ) − (τ² + 2τ + 1) L{g(τ+1)} = e^(−1)/(s + 1) − (2/s³ + 2/s² + 1/s)

Step 3 — put it together

L{t²} = 2/s³ 2 ⎡ e^(−1) 2 2 1 ⎤ L{f(t)} = ─── + e^(−s)⎢ ─────── − ─── − ─── − ─── ⎥ s³ ⎣ (s + 1) s³ s² s ⎦
Answer
f(t) = t² + (e^(−t) − t²) u(t − 1) 2 ⎡ e^(−1) 2 2 1 ⎤ L{f(t)} = ─── + e^(−s)⎢ ─────── − ─── − ─── − ─── ⎥ s³ ⎣ s + 1 s³ s² s ⎦
Where marks go

The commonest error is writing L{e−tu(t−1)} as e−s/(s+1). You must replace t by τ + 1 first, which is what produces the extra e−1 factor. Same for t² — it becomes (τ+1)², not τ².

2 (b)3 marksDivision by t + integral property
Evaluate ∫₀∞ e−t ( ∫₀t (e−3u − e−6u)/u du ) dt using the Laplace transform.

Step 1 — recognise the shape

The outer integral is exactly L{g(t)} evaluated at s = 1, where g(t) is the inner integral.

Let h(u) = (e^(−3u) − e^(−6u))/u , g(t) = ∫₀ᵗ h(u) du Required value = L{g(t)} at s = 1

Step 2 — transform of h using the f(t)/t rule

L{f(t)/t} = ∫ₛ^∞ F(p) dp L{e^(−3t) − e^(−6t)} = 1/(s+3) − 1/(s+6) ∞ ⎡ 1 1 ⎤ L{h(t)} = ∫ ⎢ ─────── − ───────⎥ dp s ⎣ p + 3 p + 6 ⎦ ∞ = [ ln((p+3)/(p+6)) ] s = 0 − ln((s+3)/(s+6)) = ln((s+6)/(s+3))

Step 3 — transform of the integral

L{ ∫₀ᵗ h(u) du } = L{h(t)}/s 1 ⎛ s + 6 ⎞ L{g(t)} = ─── ln ⎜ ───────⎟ s ⎝ s + 3 ⎠ At s = 1: ln(7/4)
Answer
ln(7/4) ≈ 0.5596
2 (c)3 marksProduct to sum, then multiply by t
Find the Laplace transform of f(t) = t e−2t sin(3t) cos(2t).

Step 1 — turn the product into a sum

Never attack sin·cos directly. Use 2 sin A cos B = sin(A+B) + sin(A−B).

sin(3t)cos(2t) = ½[ sin(5t) + sin(t) ] f(t) = ½ t e^(−2t)[ sin 5t + sin t ]

Step 2 — transform of t sin(at)

2as L{t sin at} = ────────── (s² + a²)²

Step 3 — first shifting theorem (s → s + 2)

1 ⎡ 10(s+2) 2(s+2) ⎤ L{f} = ── ⎢ ───────────────── + ───────────────── ⎥ 2 ⎣ ((s+2)² + 25)² ((s+2)² + 1)² ⎦ 5(s + 2) (s + 2) = ───────────────── + ───────────────── ((s+2)² + 25)² ((s+2)² + 1)²
Answer
5(s + 2) (s + 2) L{f} = ───────────────── + ───────────────── ((s+2)² + 25)² ((s+2)² + 1)²
Order matters

Do the product-to-sum first, then the t-multiplication, then the e−2t shift last. Shifting first and then differentiating in s is far messier and is where the algebra usually collapses.

3 (a)4 marksIVP by Laplace
Solve y″ − 6y′ + 9y = t²e3t, y(0) = 2, y′(0) = 6, using the Laplace transform.

Step 1 — transform both sides

L{y″} = s²Y − s y(0) − y′(0) = s²Y − 2s − 6 L{y′} = sY − y(0) = sY − 2 L{t²e^(3t)} = 2/(s − 3)³ (s²Y − 2s − 6) − 6(sY − 2) + 9Y = 2/(s − 3)³

Step 2 — collect Y

(s² − 6s + 9)Y = 2/(s − 3)³ + 2s + 6 − 12 (s − 3)² Y = 2/(s − 3)³ + 2s − 6 = 2/(s − 3)³ + 2(s − 3) 2 2 Y = ───────── + ─────── (s − 3)⁵ s − 3

Step 3 — invert

L^(−1){ 1/(s − 3)⁵ } = t⁴e^(3t)/4! = t⁴e^(3t)/24 L^(−1){ 1/(s − 3) } = e^(3t) y(t) = 2·t⁴e^(3t)/24 + 2e^(3t) = t⁴e^(3t)/12 + 2e^(3t)
Answer
y(t) = t⁴e^(3t)/12 + 2e^(3t)

Check: y(0) = 2 ✓ and y′(0) = 6 ✓, and substituting back into the equation gives exactly t²e3t.

3 (b)3 marksConvolution theorem
Using the convolution theorem, find the inverse Laplace transform of F(s) = s/(s² + 4)².

Step 1 — split into two known transforms

s s 1 ────────── = ──────── · ──────── (s² + 4)² (s² + 4) (s² + 4) L^(−1){ s/(s²+4) } = cos 2t L^(−1){ 1/(s²+4) } = ½ sin 2t

Step 2 — apply the convolution theorem

L^(−1){F·G} = ∫₀ᵗ f(u) g(t − u) du t y(t) = ∫ cos(2u) · ½ sin(2(t − u)) du 0 Use 2 sin A cos B = sin(A+B) + sin(A−B) with A = 2(t−u), B = 2u : ½ · ½ ∫₀ᵗ [ sin(2t) + sin(2t − 4u) ] du = ¼ [ u sin 2t + cos(2t − 4u)/4 ]₀ᵗ = ¼ [ t sin 2t + (cos(−2t) − cos 2t)/4 ] = ¼ t sin 2t (the cosine terms cancel)
Answer
y(t) = (t sin 2t)/4

Cross-check without convolution: the standard result L{t sin at} = 2as/(s²+a²)² with a = 2 gives L{t sin 2t} = 4s/(s²+4)², so s/(s²+4)² = ¼L{t sin 2t}. Same answer — worth writing as a one-line verification if you have time.

3 (c)3 marksInverse of a logarithm
Find the inverse Laplace transform of F(s) = ln((s² + 1)/(s² + 4)).

Step 1 — the rule to use

Whenever the transform is a logarithm, differentiate it. The property is L{t f(t)} = −F′(s).

F(s) = ln(s² + 1) − ln(s² + 4) 2s 2s F′(s) = ─────── − ─────── s² + 1 s² + 4

Step 2 — invert the derivative

L{t f(t)} = −F′(s) ⎧ 2s 2s ⎫ t f(t) = −L^(−1) ⎨ ─────── − ───────⎬ ⎩ s² + 1 s² + 4 ⎭ = −(2 cos t − 2 cos 2t) = 2 cos 2t − 2 cos t

Step 3 — divide by t

2(cos 2t − cos t) f(t) = ────────────────── t
Answer
f(t) = 2(cos 2t − cos t) / t
Sign trap

The property carries a minus sign: L{t f(t)} = −F′(s). Drop it and you get the answer with the cosines the wrong way round, which costs the whole mark even though the method is right.

2 (a)5 marksProof + application

The sign that catches people

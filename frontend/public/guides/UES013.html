Formula sheet

Only what these five papers actually needed, grouped by topic. Each formula checked against its standard form.

DC networks

KCL: ΣIin = ΣIout  ·  KVL: ΣV = 0 around any loop
The basis of nodal analysis (KCL at each node) and mesh analysis (KVL in each loop).
VTh = open-circuit voltage across a-b
RTh = resistance seen from a-b with voltage sources shorted and current sources opened. With a dependent source, don't switch it off — use RTh = Voc / Isc, or apply a test source.
Maximum power: RL = RTh,   Pmax = VTh² / (4RTh)
Asked as a numerical (Oct 2024, Mar 2025) and as a derivation (Oct 2025).
Source conversion: V = I·R ⇄ I = V / R
A voltage source with series R becomes a current source with the same R in parallel, and vice versa.
Superposition: total response = sum of responses to each source alone
Switch off the other independent sources (voltage → short, current → open); leave dependent sources on.

Transients

τ = L / R (RL)  ·  τ = RC (RC)
R is the equivalent resistance seen by L or C after switching.
x(t) = x(∞) + [x(0) − x(∞)]·e−t/τ
One formula for every first-order transient — current in RL, voltage in RC. Find x(0) from before switching and x(∞) from after.
RL growth: i(t) = (E/R)(1 − e−Rt/L),   i(τ) = 0.632·E/R
The Oct 2025 derivation. At t = τ the current reaches 63.2% of its final value.
vC(0⁺) = vC(0⁻),   iL(0⁺) = iL(0⁻)
Capacitor voltage and inductor current can't jump. In DC steady state, C acts as an open circuit and L as a short circuit.

Single-phase AC

XL = 2πfL,   XC = 1 / (2πfC)
ω = 2πf, so 314 rad/s in the Oct 2025 paper means f = 50 Hz.
Z = √[R² + (XL − XC)²],   I = V / Z,   φ = tan⁻¹[(XL − XC) / R]
Power factor = cos φ = R / Z. Lagging if XL > XC.
P = VI cos φ = I²R,   Q = VI sin φ,   S = VI,   S² = P² + Q²
Units: P in W, Q in VAR, S in VA.
Resonance: f0 = 1 / (2π√(LC)),   Z = R,   VL = VC = I·XL
At resonance XL = XC, so the current is maximum (I = V / R). For the stray-capacitance problem, use total C = C + Cs at both frequencies and solve the two equations.
Vrms = √[(1/T)∫v² dt],   Vavg = (1/T)∫v dt
Form factor = Vrms / Vavg; peak factor = Vmax / Vrms. For a sine wave, the average is taken over half a cycle: Vavg = 2Vm/π = 0.637Vm, Vrms = Vm/√2 = 0.707Vm, form factor 1.11, peak factor 1.414. For a half-rectified wave like the Mar 2024 question, average over the full period T.

Three-phase

Star: VL = √3·Vph, IL = Iph  ·  Delta: VL = Vph, IL = √3·Iph
Both relations were asked as derivations (delta in Oct 2025, star in Mar 2026) — learn the phasor diagram for each.
P = √3·VLIL cos φ = 3·VphIph cos φ
Reactive: Q = √3·VLIL sin φ. Apparent: S = √3·VLIL.
Two-wattmeter: P = W1 + W2,   tan φ = √3(W1 − W2) / (W1 + W2)
Total reactive power = √3(W1 − W2). Use the magnitude of the difference for the power factor.

Magnetic circuits

MMF = N·I (AT),   H = NI / l,   B = Φ / A,   B = μ0μrH
μ0 = 4π × 10⁻⁷ H/m.
Reluctance S = l / (μ0μrA),   Φ = MMF / S
Reluctances in series add, like resistors. For an air gap, μr = 1, so MMFgap = Φ·lg / (μ0A).
Series inductors: L = L1 + L2 ± 2M
+ for flux aiding, − for flux opposing (Oct 2025 derivation).

Transformer

E = 4.44·f·N·Φm
RMS EMF equation — the derivation asked in both Oct 2025 and Mar 2026. Φm = E / (4.44 f N) gives the peak flux.
V1 / V2 = N1 / N2 = I2 / I1
Ideal transformer. Full-load current: I = S / V (S in VA) for each winding.

Digital electronics

Two's complement = invert all bits + 1;   A − B = A + (2's complement of B)
8-bit signed range: −128 to +127. Discard the final carry out of the 8th bit.
De Morgan: (A·B)' = A' + B',   (A + B)' = A'·B'
K-map: group 1s in blocks of 1, 2, 4, 8; groups can wrap around the edges.

Common mistakes that lose marks

Specific traps these five papers set — each one costs easy marks.

✕
Switching off a dependent sourceWhen finding RTh, a dependent source stays on. Use Voc/Isc or a test source. Mar 2024, Mar 2025
✕
Turning off independent sources the wrong wayVoltage source → short circuit. Current source → open circuit. Thevenin and superposition questions
✕
Using the wrong R for the time constantτ uses the resistance seen by L or C after the switch operates, not before. All papers
✕
Skipping the initial condition"Closed for a long time" means find the DC steady state first (C open, L short), then carry vC or iL across t = 0. All papers
✕
Peak vs. RMS220√2 sin(…) means Vm = 220√2 V, so Vrms = 220 V. Power calculations use RMS values (Z comes out the same from either pair: Vm/Im = Vrms/Irms). Oct 2025
✕
Comparing a sine with a cosine directlyConvert first: cos(ωt + θ) = sin(ωt + θ + 90°). Only then read the phase difference. Oct 2025
✕
Mixing star and delta valuesStar: IL = Iph, VL = √3Vph. Delta: VL = Vph, IL = √3Iph. Per-phase impedance uses phase values. Mar 2024, Oct 2024, Oct 2025
✕
Unit slips200 cm² = 0.02 m²; 2.5 mm = 2.5 × 10⁻³ m; 8 µF = 8 × 10⁻⁶ F; 60 kVA = 60,000 VA; 91.5 kHz = 91,500 Hz. Most numericals
✕
Treating the air gap like ironAir has μr = 1, and the iron and gap reluctances add in series — calculate both and add them. Which one dominates depends on the numbers: in Mar 2024 the 5 mm gap needs most of the MMF, but in Oct 2024 the iron (μr = 300, 150 cm) needs more. Mar 2024, Oct 2024, Mar 2026
✕
Transformer current ratio upside downCurrents go opposite to turns: I₂/I₁ = N₁/N₂. The side with more turns carries less current. Mar 2024, Oct 2024, Oct 2025
✕
Ignoring stray capacitance at resonanceCs is in parallel with C, so f₀ uses C + Cs at both settings. Oct 2025
✕
Keeping the final carry in two's complementIn 8-bit arithmetic, discard the carry out of the 8th bit. In K-maps, don't miss groups that wrap around the edges. Mar 2025
✕
Skipping the phasor diagramWhen a question says "draw the phasor diagram," that's a separate part of the question — skipping it loses that part, even if the numbers are right. Four of five papers

If you only have one evening

  1. Nodal analysis and Thevenin / maximum power — including one circuit with a dependent source. Asked in 5/5 papers.
  2. First-order transients — practise the x(t) = x(∞) + [x(0) − x(∞)]e−t/τ method on one RL and one RC circuit.
  3. Series RLC and resonance numericals — Z, I, power factor, power, f0.
  4. Three-phase — star/delta relations with phasor diagrams, plus one two-wattmeter numerical.
  5. Transformer — the EMF equation derivation and one turns-ratio / full-load current numerical.
  6. If time is left: one magnetic circuit with an air gap.

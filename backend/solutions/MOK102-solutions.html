Q114 marksCNC programming

5 of 5 papers · 77 marks · the biggest type by far

Write a CNC part program in absolute mode to machine the stepped shaft below from a Ø60 mm bar. Measured from the free end, turn Ø35 over the first 30 mm and Ø50 over the next 40 mm, giving a 70 mm stepped shaft. Use a 2 mm depth of cut for roughing and a 0.5 mm finishing cut. Spindle 800 rpm, feed 0.2 mm/rev.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Writing any CNC turning program — the order to work in
  1. Sketch the finished part and mark the origin. Convention is the right-hand face of the finished part, on the axis. Every coordinate you write afterwards is measured from there, so fixing it first prevents every later error.
  2. Decide absolute (G90) or incremental (G91). Absolute is safer in an exam because each line stands alone and a single mistake does not cascade through the rest of the program.
  3. Remember that on a lathe, X is a diameter, not a radius. A cut to Ø35 is written X35, and the tool has moved only 12.5 mm inward from the Ø60 bar, not 25. This single convention accounts for most lost marks on the question.
  4. Write the opening block: G21 (metric), G90 (absolute), G28 U0 W0 (home), then the tool call, then S and M03 to start the spindle.
  5. Rough the profile in passes. Each pass is the same three moves: rapid to the start in X, feed along Z, retract in X. Keep the depth of cut per pass to what the question allows.
  6. Finish the profile in one continuous pass at a lighter feed.
  7. Close the program: retract clear, M05 to stop the spindle, M30 to end and rewind.
  8. Read back through and check that every feed move is G01 with an F value, and every rapid is G00 with none. A G00 with a feed, or a G01 without one, is a mark gone.
Using the canned cycle instead of longhand
  1. If the question allows a canned cycle, G71 does the roughing in two lines instead of a dozen, so use it when the profile has several steps.
  2. Line one: G71 U(depth per pass) R(retract). Line two: G71 P(first block of profile) Q(last block) U(X finishing allowance) W(Z allowance) F(feed).
  3. Between P and Q, write the finished profile once as plain G01 moves. The cycle repeats it for you at increasing depths.
  4. Then G70 P Q F runs the finishing pass along the same profile.
  5. If the question says 'write the part program' without qualification, longhand is always accepted and canned cycles are a bonus. If it says 'using G71', longhand will not score.
Reading the common G and M codes
  1. G00 rapid, G01 feed straight, G02 clockwise arc, G03 anticlockwise arc, G04 dwell.
  2. G20 inch, G21 metric. G90 absolute, G91 incremental. G28 return to reference.
  3. For an arc you must give the centre: I and K are the offsets from the start point to the centre, not from the origin. Alternatively give R.
  4. M03 spindle clockwise, M04 anticlockwise, M05 stop, M06 tool change, M08 coolant on, M09 off, M30 program end and rewind.

Step 1 — set the origin and list every diameter change

Put the origin at the centre of the finished face. X is a diameter on a lathe, not a radius — X50 means Ø50. Getting this wrong halves every cut.

from the bar at D60, working from the free end inwards: Z 0 to Z -30 : D60 -> D35 remove 12.5 mm on the radius Z -30 to Z -70 : D60 -> D50 remove 5.0 mm on the radius roughing at 2 mm depth, leaving 0.5 mm for finishing: D35 section : 12.0/2 = 6 -> 6 roughing passes D50 section : 4.5/2 = 2.25 -> 3 roughing passes cut the D35 end first: it is the smallest, so the tool never has to cut past a larger step standing behind it

Step 2 — the program

Write the safety block first, then rough, then finish in one continuous pass. A finishing pass that stops and restarts leaves a witness mark, which is a real answer-sheet detail.

N10 G21 G90 G95 ; mm, absolute, feed per revolution N20 G28 U0 W0 ; reference return N30 M03 S800 ; spindle on, clockwise N40 T0101 ; roughing tool N50 G00 X62 Z2 ; rapid to clear start ; ---- roughing the D35 end, Z0 to Z-30 ---- N60 G00 X56 Z0 N70 G01 Z-30 F0.2 N80 G00 X62 N90 G00 Z0 ; repeat at X52, X48, X44, X40, X36 ; ---- roughing the D50 part, Z-30 to Z-70 ---- N100 G00 X56 Z0 N110 G01 Z-70 F0.2 N120 G00 X62 ; repeat at X52, X51 ; ---- finishing, one continuous pass ---- N200 T0202 ; finishing tool N210 G00 X35 Z2 N220 G01 Z-30 F0.1 N230 X50 N240 Z-70 N250 X62 N260 G00 X100 Z100 N270 M05 N280 M30

Step 3 — if canned cycles are allowed, say so and use them

Most of these questions expect G71 for roughing. Writing it shows you know the machine does the repetition for you, and it saves you twenty lines of answer sheet.

N60 G71 U2 R1 ; 2 mm depth, 1 mm retract N70 G71 P80 Q140 U0.5 W0.1 F0.2 ; finish allowance 0.5 on X, 0.1 on Z N80 G00 X35 ; profile start N90 G01 Z-30 N100 X50 N110 Z-70 N140 X62 ; profile end
Answer
The program above, with G71 as the preferred roughing route.
If the question comes in a different form
If it says milling instead of turning

Everything about the structure stays the same — safety block, rough, finish — but two things change and both change every coordinate you write. On a lathe X is a diameter; on a mill X and Y are ordinary coordinates measured from the origin, so no halving and no doubling. And a milling cutter has width, so the tool centre cannot follow the profile line: it has to run offset by half the cutter diameter. Let the machine do that with G41 (offset left of the path) or G42 (offset right), and cancel it with G40 before you finish.

turning : X50 means diameter 50, so the tool sits at radius 25 milling : X50 means the tool centre is at x = 50 with a 10 mm cutter on a 60 x 60 pocket: G41 D01 ; offset left, tool radius 5 mm stored in D01 G01 X5 Y5 ; the machine now keeps the EDGE on the profile ... G40 ; cancel before retracting
If it asks for incremental instead of absolute

G90 is absolute — every number is measured from the origin, which never moves. G91 is incremental — every number is the distance from wherever the tool is standing right now. Converting is mechanical: subtract each point from the one before it. The block where people go wrong is always the first one after switching, because that distance is measured from the last absolute position, not from the origin.

absolute (G90) incremental (G91) X50 Z0 X50 Z0 (from the start point) X50 Z-30 X0 Z-30 (30 further along Z, X unchanged) X35 Z-30 X-15 Z0 (15 in on X, Z unchanged) X35 Z-70 X0 Z-40
If it also asks for machining time

The program is then only half the marks. Time is computed per pass and multiplied, and the length you use is the cut length plus any approach or overtravel the question gives you. Questions state that approach distance deliberately — if it is mentioned, it is meant to be added.

time per pass = (cut length + approach) / (feed x rpm) for 70 mm of cut, 5 mm approach, f = 0.2 mm/rev, N = 800: = 75 / (0.2 x 800) = 0.47 min per pass x 9 roughing passes + 1 finishing = 4.7 min
If canned cycles are not allowed

Some papers say "without using canned cycles". Then you write every pass out longhand, which is what the long version above does. Do not panic about the length — the marks are for the pattern being right, and you can write the first two passes in full and then put "repeat at X48, X44, X40" as a comment. Examiners accept that; writing forty near-identical blocks wastes time you need elsewhere.

One rule that applies whatever form it takes

Always leave a finishing allowance. Rough down to the final size and there is nothing left for the finishing tool, which is the one thing examiners look for in every version of this question. Leave 0.5 mm on the radius and 0.1 mm on the face unless the question says otherwise.

Q210 marksTurning calculations

4 of 5 papers · 46 marks

A Ø60 mm bar, 200 mm long, is turned in two passes with a 2 mm depth of cut per pass. The cutting speed is 60 m/min and the feed 0.25 mm/rev. The tool approaches 10 mm before the cut starts. Find (i) the spindle speed, (ii) the cutting velocity in each pass, (iii) the MRR in each pass, and (iv) the total machining time.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Riser design — Chvorinov's rule, step by step
  1. Chvorinov's rule is t = k(V/A)². The whole of riser design is the single requirement that the riser must freeze later than the casting, which means the riser needs the larger V/A.
  2. Work out V and A for the casting from its dimensions. Be careful about which faces are exposed — a face against the mould counts, a face covered by the riser does not.
  3. Work out V and A for the riser in terms of its unknown dimension. For a cylindrical riser of diameter D and height H, V = πD²H/4 and A = πDH + πD²/4 for a top riser open on one face.
  4. If the question fixes the shape, such as H = D, substitute that relation first so you are left with one unknown.
  5. Set (V/A)riser equal to or greater than (V/A)casting and solve for the dimension.
  6. State the freezing ratio you achieved. Anything slightly above 1 is correct; a value below 1 means the riser would freeze first and is useless, so re-check.
  7. A cylinder with H = D gives the largest V/A for a given volume, which is why it is the standard shape. Say so if asked to justify the choice.
Naming and explaining a casting defect
  1. Give the defect a one-line definition — what it physically is, not just where it appears.
  2. Give its cause in terms of a mechanism: gas trapped, metal solidifying too early, mould material washing away, uneven contraction.
  3. Give the remedy, and make it follow directly from the cause you just stated. A remedy that does not answer your own stated cause reads as memorised and loses marks.
  4. If a sketch is asked for, show the defect on a section of the casting with the mould around it.
  5. Structure your answer as: what it is, why it happens, how to prevent it. Three short lines each beat one long paragraph.

Step 1 — spindle speed from the starting diameter

The speed is set once, at the start, and then stays fixed. Every later change in velocity comes from the diameter shrinking, not from the machine.

N = 1000 V / (pi D0) = 1000 x 60 / (pi x 60) = 318.3 rev/min set N = 320 rev/min (machines take discrete steps)

Step 2 — velocity falls with every pass

This is the whole point of the question. With N fixed, a smaller diameter means a lower surface speed.

pass 1: D = 60 mm V = pi D N /1000 = pi x 60 x 320/1000 = 60.32 m/min pass 2: D = 56 mm V = pi x 56 x 320/1000 = 56.30 m/min (D drops by 2d = 4 mm, not by 2 mm) average over the two passes = 58.31 m/min

Step 3 — MRR per pass

MRR = 1000 x V x f x d pass 1: 1000 x 60.32 x 0.25 x 2 = 30 159 mm3/min pass 2: 1000 x 56.30 x 0.25 x 2 = 28 149 mm3/min check the other way: MRR = f x d x (pi D N) = 0.25 x 2 x pi x 60 x 320 = 30 159 mm3/min - agrees

Step 4 — time, including the approach

The approach distance is given for a reason. Add it to the length.

time per pass = (L + approach)/(f N) = (200 + 10)/(0.25 x 320) = 2.625 min total for 2 passes = 5.25 min
Answer
N = 320 rev/min · V = 60.32 and 56.30 m/min · MRR = 30 159 and 28 149 mm³/min · total time 5.25 min.
If the question comes in a different form
If it asks for parts per hour instead of machining time

Work out the time for one part exactly as above, then remember that a machine is not cutting the whole time. If the question gives a handling or loading time, that has to go into the same sum — the machine is idle during it but the clock is not.

parts per hour = 60 / (machining time + handling time) machining 3.07 min, handling 0 min -> 60/3.07 = 19.5 parts/hour machining 3.07 min, handling 0.5 min -> 60/3.57 = 16.8 parts/hour
If it gives you the time and asks for the feed

Same three relations, run backwards. This catches people out only because it looks unfamiliar; the algebra is one line. Rearrange the time formula for f and put the numbers in.

time = (L + approach)/(f N) -> f = (L + approach)/(time x N) for 160 mm of travel, 3.2 min over 2 passes, N = 320: time per pass = 1.6 min f = 160/(1.6 x 320) = 0.31 mm/rev
If roughing and finishing have different depths

Take the finishing cut out of the total before you divide, then add it back as one pass. Dividing the whole depth by the roughing depth gives a fractional number of passes and a wrong answer.

total depth 5 mm, roughing 1.5 mm/pass, finishing 0.5 mm: wrong : 5 / 1.5 = 3.33 passes right : (5 - 0.5)/1.5 = 3 roughing passes, then 1 finishing = 4 total
If the word "maximum" appears anywhere

The spindle speed is fixed, so the cutting velocity is highest at the largest diameter and falls as the bar gets thinner. If the question asks for maximum cutting velocity, quote the value at the starting diameter. If it asks for the velocity "in each pass", you must give one value per pass — a single averaged number will not score.

If the depth of cut is what you are given

Remember it comes off the radius, so the diameter falls by twice the depth. A 2 mm cut on a Ø60 bar leaves Ø56, not Ø58. Every velocity and MRR after that point depends on getting this right, so it is worth writing the diameter sequence down before you start calculating.

D0 = 60, d = 2 mm per pass: after pass 1 : 60 - 2(2) = 56 mm after pass 2 : 56 - 2(2) = 52 mm after pass 3 : 52 - 2(2) = 48 mm
Q310 marksRolling

5 of 5 papers · 50 marks

A slab 36 mm thick is to be rolled down to 16 mm on a tandem mill. The coefficient of friction is 0.15 and the roll radius is 250 mm. The slab enters the first stand at 18 m/min and the width increases by 5% at each stand. Find the minimum number of stands, the thickness after each stand, and the velocity leaving each stand.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Any rolling numerical — the standard route
  1. Write down the draft first: Δh = h0 − h1. Almost everything else is expressed in terms of it.
  2. Maximum possible draft is Δhmax = μ²R. If the question asks whether a given draft is achievable, compare against this and say so explicitly.
  3. Contact length L = √(RΔh). This is the approximation used throughout, and the question expects it.
  4. Roll force F = L × w × Ȳ, where w is the strip width and Ȳ is the average flow stress.
  5. True strain ε = ln(h0/h1). Average flow stress for a strain-hardening material is Ȳ = Kεn/(1+n).
  6. Torque per roll T = FL/2, and power for two rolls P = 2πNT with N in revolutions per second.
  7. Check the units before the last line. N given in rpm must be divided by 60, and a power answer should come out in tens or hundreds of kW — if you get megawatts, the rpm conversion is missing.
Volume constancy — the shortcut that saves the question
  1. In all bulk deformation, volume is conserved: h0w0L0 = h1w1L1.
  2. In flat rolling the width barely changes, so w0 ≈ w1 and it reduces to h0L0 = h1L1.
  3. That gives the exit length or the exit velocity in one line: v1 = v0h0/h1.
  4. The same principle answers forging height-to-diameter questions, and extrusion and drawing area questions, without any force analysis at all. If a question only asks for a final dimension, reach for this before anything else.

Step 1 — maximum draft, and mind the radius

The maximum bite a stand can take is fixed by friction and roll radius. The relation uses the radius, not the diameter — this is where most marks are lost on this question.

d_max = mu^2 R = 0.15^2 x 250 = 5.625 mm

Step 2 — number of stands

total reduction = 36 - 16 = 20 mm stands = ceil(20 / 5.625) = ceil(3.56) = 4 stands

Step 3 — the schedule, with the last stand taking the remainder

The first three stands take the full draft; the last takes only what is left. Giving the last stand its maximum too would overshoot the finished thickness.

36.00 -> 30.38 -> 24.75 -> 19.12 -> 16.00 mm drafts: 5.62 , 5.62 , 5.62 , 3.12 mm

Step 4 — velocities by volume constancy

Volume in equals volume out at every stand: h × w × v is constant. The width grows 5% each time, and that growth compounds.

h0 w0 v0 = h1 w1 v1 entry : h = 36.00 w = 1.000 v = 18.00 m/min stand 1 : h = 30.38 w = 1.050 v = 20.32 m/min stand 2 : h = 24.75 w = 1.103 v = 23.75 m/min stand 3 : h = 19.12 w = 1.158 v = 29.27 m/min stand 4 : h = 16.00 w = 1.216 v = 33.32 m/min
Answer
4 stands · 36 → 30.38 → 24.75 → 19.12 → 16 mm · exit velocities 20.32, 23.75, 29.27 and 33.32 m/min.
If the question comes in a different form
If it asks for the minimum coefficient of friction

Same relation, solved for μ instead of for the draft. The question usually gives a draft it wants achieved in a single pass and asks what friction is needed to bite it.

d_max = mu^2 R -> mu_min = sqrt(d / R) to take a 15 mm draft on a roll of 600 mm DIAMETER: R = 300 mm (not 600) mu_min = sqrt(15/300) = 0.224
If it asks for forward slip

Forward slip is how much faster the strip leaves than the roll surface moves. You need the exit velocity first, so if the parts are printed in an order that makes that impossible, do them out of order and say so in one line — examiners accept that and it costs you nothing.

s = (v_exit - v_roll) / v_roll roll surface 45.92 m/min, strip leaving at 50.00 m/min: s = (50.00 - 45.92)/45.92 = 0.0889 = 8.89 % and the roll surface speed itself is v_roll = pi D N / 1000
If the width is said to stay constant

Some papers say plane strain, or simply do not mention spreading. Then the width cancels out of the volume relation entirely and the arithmetic gets much shorter — h x v alone is constant. Read that line before you start, because carrying a width term that was never there wastes time and invites a slip.

width growing 5 % each pass: h0 w0 v0 = h1 w1 v1 width constant : h0 v0 = h1 v1 36 x 18 = 30.38 x v1 -> v1 = 21.33 m/min (against 20.32 m/min when the width grows)
If it asks how many passes rather than how many stands

Same number. A tandem mill has one stand per pass, so the answers are identical — the question is just worded from the material's point of view instead of the mill's. Do not go looking for a different method.

The one thing to check in every version

Whether you have been given the roll diameter or the roll radius. The relation needs the radius. A 500 mm diameter roll is R = 250 mm, and putting 500 in doubles every draft, which changes the number of stands and therefore every velocity after it. Write "R = ..." as your first line and the mistake becomes impossible.

Q46 marksForging

5 of 5 papers · 32 marks

Classify forging processes and explain, with a neat sketch, the function of flash in closed die forging. Why is a flashless process used at all?
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Describing any forging, extrusion or drawing process
  1. Open with one sentence saying what the process does — the shape change it produces.
  2. Draw the sketch before writing the paragraph. If the question says 'with a neat sketch', the sketch carries marks of its own and an unlabelled drawing scores nothing.
  3. Label the workpiece, the tooling, the direction of force and the direction of material flow. Those four labels are what the examiner looks for.
  4. Then describe the sequence in three or four steps: how the work is loaded, what the tool does, what happens to the material, how the part comes out.
  5. State one advantage and one limitation. This is almost always worth a mark and is almost always left out.
  6. If the question asks you to compare two processes, use a two-column table. It is faster to write and easier to mark than prose.
Open-die versus closed-die forging — the points that matter
  1. Open die: the work is not fully enclosed, so material spreads freely sideways. Simple tooling, wide range of sizes, poor dimensional control.
  2. Closed die (impression die): the cavity defines the shape. Good accuracy and good grain flow, but expensive tooling, so it needs volume to pay off.
  3. Flash is the thin ring of excess metal squeezed out at the parting line. It is deliberate, not a defect: its resistance to flow is what forces the metal to fill the cavity completely.
  4. Flashless forging needs the billet volume controlled precisely, because there is nowhere for excess metal to go.

Step 1 — the classification, on two axes

Answer on both axes. Answering on only one is what turns a full-mark answer into half marks.

by temperature: hot forging | warm forging | cold forging by die type: open die | impression (closed) die | flashless by equipment: hammer (impact) | press (squeeze)

Step 2 — what flash actually does

Flash is not waste that happens by accident. It is a designed restriction, and it does two jobs.

1. It acts as a pressure valve. Once the thin flash land fills, metal can only escape slowly, so pressure inside the cavity rises sharply and forces the metal into the thin and detailed parts of the die. 2. It takes the excess. The billet is deliberately oversized so the cavity is certainly full; the surplus has to go somewhere, and the flash gully takes it. thin flash land -> higher resistance -> higher die pressure -> better filling

Step 3 — and why flashless exists

Flash is trimmed off and scrapped, so it is wasted material and a second operation. Flashless forging needs an exactly measured billet - too little and the cavity does not fill, too much and the dies are damaged. It buys material saving at the cost of much tighter billet control.
Answer
Classification on all three axes, flash as a pressure valve and an overflow, and flashless as the material-saving trade against billet accuracy.
If the question comes in a different form
If it names a specific component

Crankshaft, connecting rod, spanner, hand tools — the answer becomes the sequence of operations rather than the classification. Name the stages in order and say what each one does to the metal.

billet -> fullering (reduce section where the part is thin) -> edging (gather metal where the part is thick) -> blocking (rough shape, generous radii) -> finishing (final impression, flash forms) -> trimming (flash cut off) and the reason it is forged at all: the grain flow follows the shape instead of being cut across, which is what gives fatigue strength
If it asks open die versus closed die

Answer as a table on five headings. A paragraph covering the same ground scores less because the examiner has to hunt for each point.

open die closed die die cost low high shape complexity simple only complex possible material waste high lower (flash only) production rate low high tolerance poor good suits one-off, large mass production
If it asks about forging defects

Name the defect, then its cause — the cause is where the marks are. Just listing names gets about half.

lap metal folds over itself, usually from a sharp corner or too large a draft in one blow cold shut two metal fronts meet but do not weld, from a too-cold billet or too-thin a section incomplete filling not enough material, or too fast a blow so the metal cannot reach the thin parts die shift top and bottom dies misaligned, so the part steps
If it asks why flash exists at all

This is the part that separates answers. Flash is not an accident and it is not only waste. The thin flash land resists the metal escaping, so pressure inside the cavity rises sharply, and that pressure is what forces metal into the thin and detailed corners of the die. The overflow function is the second reason, not the first.

Q56 marksTool geometry & angles

4 of 5 papers · 27 marks

A single point cutting tool has the signature 8–6–7–7–10–15–0.8. Identify each element. Explain the effect of the rake angle and the nose radius on the cutting operation.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Answering any cutting-tool or machining-parameter question
  1. Identify which of the three parameters the question is about: cutting speed v (m/min), feed f (mm/rev), depth of cut d (mm).
  2. Cutting speed and spindle speed are linked by v = πDN/1000 with D in mm. Almost every machining numerical starts by rearranging this.
  3. Machining time = length of cut / (f × N). Add the approach and overtravel to the length if the question gives them.
  4. Material removal rate for turning = 1000 × v × f × d in mm³/min.
  5. For tool life use Taylor's equation vTn = C. Given two conditions, divide one equation by the other — C cancels and you are left with a single unknown.
Tool signature — reading the seven numbers
  1. The order is fixed: back rake, side rake, end relief, side relief, end cutting edge angle, side cutting edge angle, nose radius. Learn the order, because the question often just gives seven numbers.
  2. Rake angles control chip flow and cutting force. Positive rake cuts more easily and is for softer materials; negative rake is stronger and is for hard materials and interrupted cuts.
  3. Relief angles stop the tool flank rubbing the finished surface. Too small and the tool burnishes and wears; too large and the cutting edge is weak.
  4. Nose radius improves surface finish and edge strength, but too large increases the radial force and invites chatter.
  5. If asked to explain one angle, always give both what it does and what goes wrong at each extreme. That pair is the full mark.

Step 1 — the signature, in its fixed order

The order never changes. Learn it once and this part is free marks.

8 deg back rake angle 6 deg side rake angle 7 deg end relief angle 7 deg side relief angle 10 deg end cutting edge angle (ECEA) 15 deg side cutting edge angle (SCEA) 0.8 mm nose radius order: the two rakes, then the two reliefs, then the two cutting edge angles, then the nose radius in mm - the only one that is not in degrees

Step 2 — rake angle, both directions

Every angle question wants the trade, not just one side.

positive rake : lower cutting force and power, better chip flow, better finish on ductile material - but a weaker cutting edge negative rake : strong edge, takes impact and interrupted cuts, suits hard material and high speed - but higher force and power zero rake : form tools and threading, where the profile must be preserved

Step 3 — nose radius, and the answer that gets the extra mark

larger nose radius -> better surface finish, stronger tip, longer tool life -> BUT higher radial force and that radial force is what makes a long slender workpiece chatter - at which point the finish gets worse, not better. Say that sentence.
Answer
All seven elements named in order, and both angles answered as a trade rather than a single benefit.
If the question comes in a different form
If it asks you to choose the rake angle for a given material

Do not write about chips alone. The question names cutting parameters — speed, feed, depth — and expects a level against each one. Put them in a table and you cannot leave one out.

negative rake positive rake cutting speed high low to medium feed high low to medium depth of cut high low to medium cutting force high low chip produced discontinuous continuous tool edge strong weaker suits hard material, ductile material, interrupted cuts finishing
If it says "for machining a ductile material"

That qualifier decides the answer and it is there on purpose. On a ductile material positive rake gives the better finish. On a hard or brittle material the answer flips — negative rake can finish better because the edge does not chip. Answering without noticing the qualifier is how a correct-looking answer loses marks.

If it asks about the nose radius

Give both directions. A larger radius gives a better finish, a stronger tip and longer tool life, but it also raises the radial force — and on a long slender workpiece that force causes chatter, at which point the finish gets worse rather than better. That last sentence is usually the mark that separates answers.

If the signature is given in a different system

ASA and ORS number the same tool differently. If the question names a system, say which one you are reading and then interpret in that order. If it names none, state that you are using ASA and carry on — stating the assumption protects the marks.

ASA order: back rake, side rake, end relief, side relief, ECEA, SCEA, nose radius the quick way to remember it: two rakes, two reliefs, two cutting edge angles, then the radius
Q65 marksChips & stress–strain

4 of 5 papers · 26 marks

Name the types of chips produced in metal cutting. For copper and for grey cast iron, state which chip forms and explain the machining conditions that promote it.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Explaining any welding process
  1. State the heat source in the first line — arc, resistance, chemical, or friction. Every other difference follows from it.
  2. Say whether it is consumable or non-consumable electrode, and whether filler is added separately.
  3. Say how the weld pool is shielded: a gas, a flux, a slag, or a vacuum. If the process has no shielding, say what happens as a result.
  4. Draw the joint in section: base metals, weld pool, electrode, shielding, and the heat-affected zone.
  5. For a comparison, pick the axes yourself and keep them consistent: heat source, shielding, filler, typical thickness, cost, one application each.
Heat input and the heat-affected zone
  1. Heat input per unit length H = VI/v, with v the travel speed. Higher current or slower travel means more heat into the joint.
  2. More heat means a wider HAZ, larger grains in it, and lower strength there. That chain of three is the answer to most HAZ questions.
  3. Melting efficiency and heat transfer efficiency both multiply the input. If the question gives them, apply both — the useful heat is H × f1 × f2.

Step 1 — the three types, with the condition behind each

continuous ductile material, positive rake, high speed, small feed, good lubrication continuous with BUE ductile material, low to medium speed, high friction, poor lubrication discontinuous brittle material, negative rake, low speed, large feed and depth

Step 2 — apply it to the two materials named

The question names two materials on purpose — one ductile, one brittle.

copper - ductile, so a continuous chip, with a built-up edge at low and medium speed. Raise the speed and use positive rake with a small feed to get a clean continuous chip. cast iron - brittle, so a discontinuous chip. It fractures ahead of the tool instead of flowing over it. Negative rake, lower speed and a larger feed suit it, and chip disposal is easy because it breaks itself.

Step 3 — if a stress–strain curve is given instead

Read it along the strain axis, not the stress axis.

chip type follows DUCTILITY - how far the curve runs along strain - not strength, which is how high it goes. A material can be both strong and ductile and will still give a continuous chip.
Answer
Three chip types with their conditions; copper → continuous with BUE at low speed, cast iron → discontinuous.
If the question comes in a different form
If it gives you stress–strain curves and asks for the chip

Read the curves along the strain axis, not the stress axis. Chip type follows ductility — how far the material stretches before it breaks — not strength, which is how high the curve goes. A material can be both strong and ductile and it will still give a continuous chip.

long run along strain, breaks late -> ductile -> continuous chip short run, breaks early -> brittle -> discontinuous chip height of the curve tells you the force needed, not the chip
If it asks about built-up edge on its own

The answer the examiner is waiting for is that BUE is not simply a defect. Once a layer of work material seizes onto the rake face it becomes the cutting edge, and while it stays put it shields the real edge from wear — in roughing that can be worth having. The damage comes from the unstable version, which grows, breaks away, drags across the finished surface and carries off a little tool material each time. The mark is for separating stable from unstable, not for condemning it outright.

BUE forms when: ductile material, low to medium speed, high friction, poor lubrication to get rid of it: raise the cutting speed, increase the rake angle, use a good cutting fluid, reduce the feed
If it asks where forming and machining sit on the curve

One line, often left blank, always worth a mark. Forming works in the plastic region between yield and ultimate — you want the metal to change shape and stay in one piece. Machining works past the ultimate point, at fracture — you want the metal to separate. Mark and shade the two bands on the ductile curve.

If it names two materials

Pick them apart by ductility first, then give conditions for each. The examiner has almost certainly chosen one ductile and one brittle material on purpose — copper and cast iron, aluminium and grey iron, mild steel and bronze. Say which is which in your first line and the rest follows.

Compare FDM and SLS on principle, materials, accuracy, support requirement and typical application. Which would you choose for a functional prototype of a load-bearing bracket, and why?
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Answering a pattern, mould or allowance question
  1. List the allowances in the order they are applied: shrinkage, machining, draft, distortion, shake. Naming them in order is often half the mark.
  2. Say what each one compensates for, in one line. Shrinkage for the metal contracting as it cools; machining for material that will be cut away later; draft so the pattern lifts without tearing the sand; distortion for warping in thin sections; shake for the pattern rapping loose.
  3. Note which way each is applied. Shrinkage and machining make the pattern larger than the casting; shake makes it slightly smaller.
  4. For a numerical, apply them multiplicatively to each dimension in turn and state the final pattern dimension clearly.
  5. For the moulding sand, the four requirements are permeability, cohesiveness, refractoriness and collapsibility. Define each in one line and say what fails if it is absent.

Step 1 — the comparison, as a table

A table earns more than a paragraph here, and it is faster to write.

FDM SLS principle filament melted and powder bed fused by laser, extruded layer by layer layer by layer material thermoplastic filament polymer / metal powder (PLA, ABS, PETG) (nylon, PA12, metals) accuracy lower, visible layer lines higher, finer detail supports needed for overhangs not needed - loose powder and must be removed supports the part strength anisotropic, weak between near isotropic, stronger layers cost low high typical use concept models, jigs functional and end-use parts

Step 2 — the choice, with the reason stated

The second half of the question is where the marks separate. Commit to an answer and justify it.

Choose SLS. A load-bearing bracket is loaded in more than one direction, and FDM parts are weak between layers - they split along the build direction. SLS parts are close to isotropic, so the bracket holds whichever way it is loaded. SLS also needs no supports, so internal features come out clean. FDM would only win if this were a shape check, where cost and speed matter more than strength.
Answer
The five-row comparison, and SLS chosen for the bracket on the isotropy argument.

If it asks about one process in depth instead of a comparison

CAD model -> export as STL (surface as triangles) -> slice into layers, generate tool path and supports -> build layer by layer -> remove from the machine, take off supports -> post-process: sanding, curing, machining, heat treat

Q84 marksSheet metal & dies

2 of 5 papers · 18 marks

A washer of 80 mm outside diameter with a 30 mm hole is to be produced from sheet. The clearance is 0.6 mm per side. Determine the punch and die sizes for both the blanking and the punching operation.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Any sheet metal numerical
  1. Decide first whether it is blanking or piercing, because the clearance goes on opposite members. In blanking the part is the slug, so the die is at size and the punch is smaller by twice the clearance. In piercing the part is the hole, so the punch is at size and the die is larger.
  2. Getting that one decision right is worth more than the rest of the question, so write it down explicitly before any arithmetic.
  3. Clearance per side c is usually given as a fraction of thickness, often around 5%. Total difference between punch and die is 2c.
  4. Cutting force F = L × t × τ, where L is the full perimeter being cut and τ is the shear strength. For a circle L = πd; for a rectangle it is the whole way round.
  5. If shear strength is not given but tensile strength is, take τ ≈ 0.7σu and say you are doing so.
  6. Stripping force is usually a stated percentage of the cutting force.
  7. Work done = F × t × a penetration factor if one is given; otherwise state the assumption.
Bending: what to add to the length
  1. Bend allowance BA = 2π(A/360)(R + kt), where A is the bend angle, R the inside radius and k the position of the neutral axis — take 0.33 for R < 2t and 0.5 for R ≥ 2t.
  2. Blank length = sum of the flat lengths + the bend allowance for each bend. Do not measure flats round the corner.
  3. Springback means the finished angle opens out slightly, so the tool must overbend. Mention it even when no number is asked for.

Step 1 — the rule that decides everything

One sentence decides both answers, and it is the only thing worth memorising here:

The member that produces the REQUIRED size is made to that size, and the clearance is given to the other member. blanking : the blank is the product -> the DIE sets the size punching : the hole is the product -> the PUNCH sets the size

Step 2 — apply it

BLANKING the 80 mm washer: die = 80.00 mm (the blank size) punch = 80 - 2(0.6) = 78.80 mm PUNCHING the 30 mm hole: punch = 30.00 mm (the hole size) die = 30 + 2(0.6) = 31.20 mm

Step 3 — the sanity check

The punch is always smaller than its die, in both operations. If yours is not, the operations have been swapped.
Answer
Blanking: die 80.00 mm, punch 78.80 mm. Punching: punch 30.00 mm, die 31.20 mm.
If the question comes in a different form
If it also asks for the force

Two formulas, and the punch force needs the cut perimeter, not the area. For a round part the perimeter is πD; for a rectangle it is twice the sum of the sides.

punch force F = perimeter x thickness x shear strength for the 80 mm blank, 2 mm sheet, shear strength 300 N/mm2: F = (pi x 80) x 2 x 300 = 150 800 N = 150.8 kN stripping force is usually taken as 5 to 20 % of the punch force, and press capacity is quoted with a factor on top of the total
If the clearance is given as a percentage of thickness

Convert it to millimetres first and then nothing else changes. Percentage clearance is always per side unless the question says otherwise.

clearance 5 % of a 2 mm sheet: c = 0.05 x 2 = 0.1 mm per side blanking an 80 mm blank: die 80.00, punch 80 - 2(0.1) = 79.80 mm punching a 30 mm hole : punch 30.00, die 30 + 2(0.1) = 30.20 mm
If it asks about a progressive die or the order of operations

The hole is punched before the blank is cut out. The reason is the mark: while the strip is still whole, it is located by the pilot holes and the feed; once the blank is cut free there is nothing holding it in position to punch accurately.

The check that works in every version

The punch is always smaller than its die, in both blanking and punching. If your numbers come out the other way, you have swapped which operation gets the clearance. It takes five seconds and it catches the single most common error in this topic.

blanking : die 80.00 > punch 78.80 correct punching : die 31.20 > punch 30.00 correct

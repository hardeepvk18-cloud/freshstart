Q112 marksDC network theorems

5 of 5 papers · 45 marks · the biggest type

For the network shown, a 24 V source feeds a 6 Ω resistor to node P. A 12 Ω resistor runs from P to ground and a 4 Ω resistor from P to terminal a. A 3 A current source drives into node a from ground. Find the Thevenin equivalent across a–b, and the value of RL that draws maximum power together with that power.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Thevenin's theorem — the full procedure
  1. Remove RL from the circuit. Everything that follows is done with those two terminals left open.
  2. Find the voltage across the open terminals. That is Vth. Use whichever method suits the circuit — nodal, mesh, or a simple divider. Mark its polarity; you will need it when you redraw.
  3. Find Rth. Kill every independent source: replace each voltage source by a short and each current source by an open. Then look back into the terminals and reduce the resistors by series and parallel.
  4. If any source is dependent, it cannot be killed. Instead short the terminals, find Isc, and take Rth = Vth/Isc.
  5. Redraw: a source Vth in series with Rth, with RL reconnected across it. Then IL = Vth/(Rth + RL).
Norton's theorem — same work, different picture
  1. Remove RL, exactly as for Thevenin.
  2. Short the two terminals together and find the current flowing through that short. That is IN.
  3. Find RN the same way you found Rth — kill the independent sources and reduce. RN is always equal to Rth for the same circuit.
  4. Redraw: a current source IN in parallel with RN, with RL across it. Then IL = IN × RN/(RN + RL) by current division.
  5. The two equivalents convert straight into each other: Vth = INRN and IN = Vth/Rth. If you have found one, the other is a single line of work.
Superposition — one source at a time
  1. Count the independent sources. You will do the circuit once per source, so with three sources you get three sub-circuits.
  2. Keep one source live and kill all the others. A dead voltage source becomes a short; a dead current source becomes an open. Getting these two the wrong way round is the commonest error in the whole topic.
  3. Solve the simplified circuit for the quantity you were asked for. Write down its value and its direction.
  4. Repeat for every source, then add all the contributions algebraically — contributions in opposite directions subtract.
  5. Superposition works for current and voltage only. It does not work for power, because power depends on the square of the current. If a question asks for power, superpose to get the total current first, then square it.
Source conversion — for collapsing a messy circuit
  1. Look for a current source that has a resistor directly in parallel with it, or a voltage source with a resistor directly in series. Only those can be converted.
  2. The conversion runs both ways. Multiply to go one way — a current source of I alongside R turns into a voltage source of value IR, now in series. Divide to come back — a voltage source of V in series with R turns into a current source of V/R, now in parallel.
  3. Combine any series or parallel resistors the conversion has now brought together.
  4. Repeat until the circuit is a single loop or a single node pair, then finish with one KVL or one KCL.
  5. The resistor never changes value in a conversion — only the source does.
Maximum power transfer
  1. Remove RL and find the Thevenin equivalent of everything else, as above.
  2. The load that draws maximum power is RL = Rth.
  3. That maximum power is Pmax = Vth²/(4Rth).
  4. If asked, note the efficiency: half the energy drawn from the source ends up heating Rth, so only 50% reaches the load. Matching for maximum power is therefore a signal-circuit idea, never a power-system one.

Step 1 — open-circuit voltage

With a–b open nothing leaves at a, so all 3 A of the source has to go back through the 4 Ω. That fixes the voltage across the 4 Ω before you solve anything else.

at node a (open): (Va - Vp)/4 = 3 -> Va = Vp + 12 at node P: (Vp - 24)/6 + Vp/12 + (Vp - Va)/4 = 0 (Vp - 24)/6 + Vp/12 - 3 = 0 x12: 2(Vp - 24) + Vp - 36 = 0 3 Vp = 84 -> Vp = 28 V Vth = Va = 28 + 12 = 40 V

Step 2 — Thevenin resistance

Kill the independent sources: the voltage source becomes a short, the current source becomes an open. A dead current source is an open circuit, not a short — that one fact decides the answer.

looking in from a: 4 ohm in series with (6 || 12) 6 || 12 = 72/18 = 4 ohm Rth = 4 + 4 = 8 ohm

Step 3 — confirm with the short-circuit current

Two independent routes to Rth is what turns a plausible answer into a certain one.

short a to b, so Va = 0: (Vp - 24)/6 + Vp/12 + Vp/4 = 0 -> Vp = 8 V Isc = Vp/4 + 3 = 2 + 3 = 5 A Rth = Vth/Isc = 40/5 = 8 ohm - agrees with step 2

Step 4 — maximum power

R_L = Rth = 8 ohm P_max = Vth^2/(4 Rth) = 1600/32 = 50 W
Answer
Vth = 40 V, Rth = 8 Ω, RL = 8 Ω and Pmax = 50 W.
If the question comes in a different form
If the source is dependent rather than independent

You cannot kill a dependent source, so the "short the voltage source, open the current source" route is not available. Rth has to come from Vth and Isc, exactly as in step 3. This has come up twice — a 2ix source in Mar 2024 and a 3Vx source in Mar 2025 — and both times the marks were for noticing the difference, not for the arithmetic.

with a dependent source: 1. find Vth with the terminals open (source stays in) 2. find Isc with the terminals shorted (source stays in) 3. Rth = Vth / Isc never: 'kill the sources and add the resistors' - that gives a wrong answer and an examiner spots it instantly
If it asks for Norton instead of Thevenin

Same circuit, same work, different final picture. The Norton current is the short-circuit current you already computed, and the resistance is identical. If you have one you have the other.

Norton: I_N = Isc = 5 A in parallel with R_N = Rth = 8 ohm Thevenin: Vth = 40 V in series with Rth = 8 ohm and the two are linked by Vth = I_N x R_N -> 5 x 8 = 40 V
If it asks for superposition

Take one source at a time and add the results with their signs. The rule people get backwards: a dead voltage source is a short, a dead current source is an open. Always state the two contributions separately before adding — the marks are for the method being visible.

24 V alone (3 A source opened) -> contribution 1 3 A alone (24 V source shorted) -> contribution 2 answer = contribution 1 + contribution 2, signs included check it by solving the full circuit once with both live
If it asks for source conversion

Take a current source sitting beside a parallel R and rewrite it as a source of value IR placed in series with that same R; the reverse direction works too, and the other way round. Use it to collapse a circuit into a single loop, then one KVL finishes it.

3 A in parallel with 4 ohm == 12 V in series with 4 ohm 24 V in series with 6 ohm == 4 A in parallel with 6 ohm
The one check to run whatever the form

Rth for a circuit with only independent sources can never be negative and can never come out larger than the sum of all the resistances in the path. If it does, a source has been killed the wrong way — almost always a current source shorted instead of opened.

Q210 marksSingle-phase AC & resonance

4 of 5 papers · 34 marks

A coil of resistance 12 Ω and inductance 0.08 H is connected in series with a 200 µF capacitor across a 230 V, 50 Hz supply. Find the current, the power factor and the power consumed. Then find the capacitance that would bring the circuit to resonance, and the voltage that would appear across the inductor at that condition.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Any series AC circuit — the order to work in
  1. Write down ω = 2πf once, at the top. Every reactance uses it.
  2. Find each reactance: XL = ωL and XC = 1/(ωC). Work them out separately before combining anything.
  3. Net reactance X = XL − XC. Its sign is the answer to half the question: positive means inductive and the current lags; negative means capacitive and the current leads; zero is resonance.
  4. Impedance Z = √(R² + X²), and the phase angle φ = arctan(X/R).
  5. Current I = V/Z, power factor = cosφ = R/Z.
  6. Powers: P = VI cosφ (watts), Q = VI sinφ (VAR), S = VI (VA). Check P against I²R — they must agree.
  7. For the phasor diagram, take I along the reference, draw VR in phase with it, VL 90° ahead and VC 90° behind, then add them to get V.
Series resonance — what changes
  1. At resonance XL = XC, so the net reactance is zero and Z = R alone.
  2. The resonant frequency is f = 1/(2π√(LC)). To find the C that resonates at a given f, rearrange: C = 1/(ω²L).
  3. At resonance the current is at its maximum, I = V/R, and the power factor is unity.
  4. The quality factor Q = XL/R = ωL/R tells you the voltage magnification: VL = VC = Q × Vsupply, so a Q of 10 puts ten times the supply voltage across each reactive element.
  5. A result many times the supply voltage is the expected answer here, not a slip. Being in antiphase, the two reactive voltages sum to nothing, leaving VR alone to balance the source. Add that sentence to your answer — it is usually what the mark is for.

Step 1 — the two reactances, and which one wins

Work out both before deciding anything. Whichever is larger decides whether the current lags or leads.

XL = 2 pi f L = 2 pi x 50 x 0.08 = 25.13 ohm XC = 1/(2 pi f C) = 1/(2 pi x 50 x 200e-6) = 15.92 ohm X = XL - XC = 9.22 ohm positive, so inductive -> current LAGS

Step 2 — impedance, current, power factor

Z = sqrt(R^2 + X^2) = sqrt(12^2 + 9.22^2) = 15.13 ohm I = V/Z = 230/15.13 = 15.20 A phi = arctan(X/R) = arctan(9.22/12) = 37.53 deg lagging pf = cos(phi) = 0.793 lagging

Step 3 — power, checked two ways

P = V I cos(phi) = 230 x 15.20 x 0.793 = 2772.6 W check: P = I^2 R = 15.20^2 x 12 = 2772.6 W - agrees

Step 4 — resonance

At resonance the reactances cancel, the impedance collapses to R alone, and the current is at its maximum.

C = 1/(w^2 L) = 1/((2 pi x 50)^2 x 0.08) = 126.7 uF then Z = R = 12 ohm and I = 230/12 = 19.17 A VL = I XL = 19.17 x 25.13 = 481.7 V

Step 5 — and why 481 V is not a mistake

481 V across the coil on a 230 V supply looks wrong and it is not. This is voltage magnification: VL and VC are equal and exactly opposite, so they cancel each other and the supply still sees only the 230 V across R.

Q = XL/R = 25.13/12 = 2.09 VL = VC = Q x V = 2.09 x 230 = 481 V - consistent
Answer
I = 15.20 A at 0.793 lagging, P = 2772.6 W. For resonance C = 126.7 µF, and then VL = VC = 481.7 V.
If the question comes in a different form
If the capacitor is larger, so the circuit is capacitive

Everything is identical until the sign of X. If XC > XL then X is negative, the angle is negative, and the current leads. The magnitude of the answer does not change; the word lagging becomes leading, and that word is worth a mark.

X = XL - XC X positive -> inductive -> current LAGS the voltage X negative -> capacitive -> current LEADS the voltage X zero -> resonance -> current IN PHASE, Z = R
If you are given v(t) and i(t) instead of components

Put both waveforms in the same form first — if one is a cosine and the other a sine, convert before comparing angles. Oct 2025 used exactly this trick and the whole question turned on it.

cos(x) = sin(x + 90) v = 220 sqrt2 sin(314t + 15) -> V = 220 at +15 deg i = 22 sqrt2 cos(314t - 30) = 22 sqrt2 sin(314t + 60) -> I = 22 at +60 deg phi = 15 - 60 = -45 deg, current leads, so R and C in series |Z| = 220/22 = 10 ohm, R = 10cos45 = 7.07, Xc = 7.07 ohm
If it asks for resonance with a stray capacitance

Two resonant frequencies at two known capacitances let you eliminate L and solve for the stray. Write the resonance condition twice and set the right-hand sides equal.

f = 1/(2 pi sqrt(L (C + Cs))) f1^2 (C1 + Cs) = f2^2 (C2 + Cs) Cs = (f2^2 C2 - f1^2 C1)/(f1^2 - f2^2) then L from either one - and check it against the other, which must return the stated frequency exactly
If it asks for power factor correction

Add a capacitor in parallel with the load, not in series. It supplies the reactive power the load was drawing from the supply, so the line current falls while the real power stays the same.

Q needed = P (tan(phi_old) - tan(phi_new)) C = Q / (2 pi f V^2) for P = 2772 W, 0.793 -> 0.95 lagging on 230 V, 50 Hz: tan(37.53) = 0.767 , tan(18.19) = 0.329 Q = 2772 (0.767 - 0.329) = 1214 VAR C = 1214/(2 pi x 50 x 230^2) = 73.1 uF
If it asks for rms, average or form factor of a waveform

Those are ratios over one full period and they do not depend on the time scale at all, so an awkward or inconsistent time axis does not matter. Square, average, root — in that order.

half-rectified square wave, peak Vp, on for half the period: Vrms = Vp/sqrt2 = 0.707 Vp Vavg = Vp/2 = 0.5 Vp form factor = Vrms/Vavg = sqrt2 = 1.414 for a full sine: form factor 1.11, peak factor 1.414
Q39 marksRL / RC transients

5 of 5 papers · 31 marks · in every single paper

In the circuit shown a 24 V source feeds 4 Ω and 8 Ω in series with a 0.5 H inductor. A switch across the 8 Ω has been closed for a long time and opens at t = 0. Find the complete expression for the current for t > 0, and the current 50 ms after switching.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Any first-order transient — the three quantities
  1. Every RL and RC switching question is answered by finding just three things, and then substituting them into one formula. Find them in this order.
  2. x(0) — the value just before switching. Redraw the circuit as it was before t = 0 in steady state: treat an inductor as a plain wire and a capacitor as an open circuit, then solve the resistive circuit.
  3. x(∞) — the final value. Redraw the circuit as it is after switching, again in steady state with the inductor a wire and the capacitor an open.
  4. τ — the time constant, computed from the circuit after switching. For an inductor τ = L/R; for a capacitor τ = RC. For R, stand at the component's own two terminals, kill the sources, and reduce what you can see from there. It is rarely the single resistor nearest the component — more often a parallel pair.
  5. Substitute: x(t) = x(∞) + [x(0) − x(∞)] e−t/τ. This one formula covers rising and falling, RL and RC, charging and discharging.
  6. Check by putting t = 0 and t = ∞ back into your expression — they must return the two values you started from.
The two continuity rules everything rests on
  1. The current through an inductor cannot change instantly, so i(0⁺) = i(0⁻).
  2. The voltage across a capacitor cannot change instantly, so v(0⁺) = v(0⁻).
  3. Everything else in the circuit can jump at t = 0 — resistor voltages, source currents, all of it. Only those two quantities carry across the switch.

Step 1 — what the switch is actually doing

With the switch closed, both terminals of the 8 Ω sit at the same potential, so no current passes through it. Opening it at t = 0 puts the 8 Ω back into the loop.

Step 2 — the initial current

Long time closed means steady state, and in steady DC an inductor is just a wire. Inductor current cannot jump, so this value carries straight across t = 0.

i(0-) = 24/4 = 6 A and i(0+) = i(0-) = 6 A

Step 3 — final current and time constant

The time constant uses the resistance the inductor sees after the switching, never before.

with the switch open, R = 4 + 8 = 12 ohm i(inf) = 24/12 = 2 A tau = L/R = 0.5/12 = 0.04167 s -> 1/tau = 24

Step 4 — assemble, then evaluate

Every first-order circuit follows the same shape: x(t) = x(∞) + [x(0) − x(∞)]e−t/τ.

i(t) = 2 + (6 - 2) e^(-24t) = 2 + 4 e^(-24t) A at t = 50 ms = 0.05 s: e^(-24 x 0.05) = e^(-1.2) = 0.3012 i = 2 + 4(0.3012) = 3.205 A solving the differential equation directly gives 3.20478 A - identical
Answer
i(t) = 2 + 4e−24t A, falling from 6 A to 2 A with a time constant of 41.7 ms; at 50 ms it is 3.21 A.
If the question comes in a different form
If the switch closes and removes resistance instead

The mirror image of this question, and it has appeared both ways. Closing a switch across a resistor takes it out of the loop, so the final current is higher than the initial one and the curve rises instead of falling. The method does not change at all — only which of i(0) and i(∞) is the larger.

switch OPENS, resistance added -> i falls (this question) switch CLOSES, resistance removed -> i rises (Mar 2025 Q3a) Mar 2025: 12 V, 2 + 4 ohm, 2 H, switch shorts the 2 ohm i(0) = 12/6 = 2 A , i(inf) = 12/4 = 3 A , tau = 2/4 = 0.5 s i(t) = 3 - e^(-2t) A
If it is a capacitor rather than an inductor

Same shape of answer, two things swapped. It is the voltage that cannot jump, not the current, and the time constant is RC rather than L/R. Everything else is identical.

inductor : current cannot jump , tau = L/R capacitor: voltage cannot jump , tau = R C x(t) = x(inf) + [x(0) - x(inf)] e^(-t/tau) works for both
If the capacitor has resistors on both sides

The resistance in τ is what the capacitor sees looking back into the circuit with the sources killed. Very often that is a parallel combination, not a series one, and this is the single most common error in RC questions.

Mar 2025 Q3b: 60 V - 6 ohm - node - 3 ohm to ground, C across the 3 ohm wrong : tau = (6 + 3) C right : tau = (6 || 3) C = 2 C with C = 2 uF: tau = 4 us, not 18 us
If the source is switched rather than removed

Then the final value is not zero — it is whatever the new source produces. Compute v(∞) from the new circuit and put it into the same expression. A pure decay only happens when the source is disconnected entirely.

source removed : v(inf) = 0 -> pure decay, v = v0 e^(-t/tau) source switched : v(inf) = new steady value 20 V to 60 V across a 6/3 divider: v(0) = 20 x 3/9 = 6.67 V , v(inf) = 60 x 3/9 = 20 V v(t) = 20 - 13.33 e^(-t/4us)
The check that works in every version

Put t = 0 and t = ∞ into your final expression. They must return the two values you started from. It takes ten seconds and it catches a wrong sign, a wrong time constant and a swapped initial value all at once.

i(t) = 2 + 4 e^(-24t) t = 0 -> 2 + 4 = 6 A matches i(0) t = inf -> 2 + 0 = 2 A matches i(inf)
Q47 marksNodal & mesh analysis

5 of 5 papers · 25 marks

Using nodal analysis, find the node voltages V1 and V2 in the network shown: a 40 V source through 5 Ω to node 1, a 10 Ω from node 1 to ground, a 4 Ω between nodes 1 and 2, an 8 Ω from node 2 to ground, and a 2 A source driving into node 2.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Nodal analysis — the procedure
  1. Mark every node. Choose the one with the most branches meeting it as the reference and call it 0 V.
  2. Any node connected to the reference through a voltage source alone is already known — write its value straight in and cross it off the list of unknowns.
  3. For each remaining unknown node, write KCL. Take every current as leaving the node and set the sum to zero; keeping one direction throughout is what prevents sign errors.
  4. A resistor branch contributes (Vthis − Vother)/R. A branch with a source in series contributes (Vthis − Vother − E)/R — account for the source before dividing.
  5. A current source entering the node contributes −I; one leaving contributes +I.
  6. If a voltage source sits directly between two unknown nodes, enclose both in a supernode: one KCL for the pair, plus the source as a constraint equation.
  7. Solve, then substitute back into each equation to check it comes to zero.
Mesh analysis — when to use it instead
  1. Use mesh when the circuit has more voltage sources than current sources; use nodal when it is the other way round. Both give the same answer — one is simply less writing.
  2. Assign a loop current to each independent loop, all in the same direction (clockwise by convention).
  3. Write KVL round each loop. A resistor shared by two loops carries the difference of their currents.
  4. If a current source sits in a branch shared by two loops, you cannot write KVL through it. Take the two loops as one supermesh: trace a path that stays clear of the offending branch, write KVL along it, and supply the missing equation by setting the difference of the two loop currents equal to the source.
  5. A negative loop current is not an error — it means the loop actually circulates the other way. Say so.

Step 1 — count the unknowns before writing anything

The source node is fixed at 40 V, so there are only two unknowns. Writing more equations than you need is where time goes on this question.

Step 2 — KCL at each node, currents taken as leaving

node 1: (V1 - 40)/5 + V1/10 + (V1 - V2)/4 = 0 node 2: (V2 - V1)/4 + V2/8 - 2 = 0 (the 2 A enters node 2, so it leaves as -2)

Step 3 — solve and check

Always substitute back. It takes one line and it catches a sign error, which is the only thing that really goes wrong in nodal analysis.

V1 = 24.35 V V2 = 21.57 V check node 1: (24.35-40)/5 + 24.35/10 + (24.35-21.57)/4 = 0 ok check node 2: (21.57-24.35)/4 + 21.57/8 - 2 = 0 ok
Answer
V1 = 24.35 V and V2 = 21.57 V.
If the question comes in a different form
If a voltage source sits between two unknown nodes

You cannot write an ordinary KCL at either end, because the current through a voltage source is unknown. Enclose both nodes in one supernode, write a single KCL around the whole boundary, and add the source as a constraint equation. Oct 2025 used exactly this.

supernode enclosing a and c, with a 10 V source between them: constraint : Va - Vc = 10 KCL round the boundary: sum of currents leaving a and c = 0 -5 + (Va - 12)/10 + 2 + (Vc - 12)/40 = 0 the source never appears in the KCL - it is inside the boundary
If a branch contains a resistor and a source in series

Dividing the node difference by the resistance will give the wrong figure here. Travel along the branch instead, taking account of the source before dividing. Mar 2025 Q1(a) was built on this.

branch: from v1, through 6k, then through a 9 V source, to v2 wrong : (v1 - v2)/6000 right : (v1 - v2 - 9)/6000
If it asks for mesh analysis instead

Same circuit, different unknowns — loop currents rather than node voltages. Use mesh when the circuit has more voltage sources than current sources, and nodal when it is the other way round. Both give the same answer; one is just less writing.

nodal : one equation per node, unknowns are voltages mesh : one equation per loop, unknowns are currents
If a current source sits in a shared branch between two meshes

Same problem in mesh form, same fix. Go round the outside of both loops (a supermesh), avoiding the source branch, and add the source as the constraint.

Mar 2025 Q2a: 1 A source in the middle branch constraint : i2 - i1 = 1 supermesh : 10 - 5 i1 - 10 i2 - 20 = 0 -> i1 = -4/3 A , i2 = -1/3 A negative just means the loop actually circulates the other way - say that in one line and the mark is safe
The check that costs one line

Substitute your answers back into the original KCL equations. Every node must come to zero. Nodal analysis almost never fails on the algebra — it fails on a sign, and this catches it.

Q57 marksThree-phase

4 of 5 papers · 25 marks

A balanced star-connected load draws 15 A per phase from a 415 V, 50 Hz three-phase supply at a power factor of 0.8 lagging. Find the phase voltage, the load resistance and reactance per phase, the total power, and the readings of two wattmeters connected to measure that power.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Any balanced three-phase problem
  1. First decide star or delta, and write down the two relations before anything else. For a star, √3 divides the voltage and leaves the current alone: Vph = VL/√3, Iph = IL. For a delta it is the mirror image — √3 divides the current and leaves the voltage alone: Vph = VL, Iph = IL/√3.
  2. Convert whatever you were given into phase quantities using those relations.
  3. Find the phase impedance Zph = Vph/Iph, and split it: R = Z cosφ, X = Z sinφ.
  4. Total power P = √3 VL IL cosφ. This same expression works for both star and delta — it is written in line quantities, which is why.
  5. Check with P = 3 Iph² R, which must give the same number.
The two-wattmeter method
  1. The two readings are W1 = VLILcos(30° − φ) and W2 = VLILcos(30° + φ).
  2. Their sum is the total power: P = W1 + W2.
  3. Their difference carries the angle: tanφ = √3 (W1 − W2)/(W1 + W2).
  4. Reactive power Q = √3 (W1 − W2).
  5. If the readings are given and the load is asked for, work backwards through the same four lines.
  6. A negative reading is normal below 0.5 power factor. Include the sign in the sum — do not drop it.

Step 1 — phase quantities in star

A star connection puts the full line current through each phase, while each phase sees only VL/√3 of the line current. Using 415 V as the phase voltage is the standard mistake in this topic.

Vph = VL/sqrt3 = 415/1.732 = 239.6 V Iph = IL = 15 A Zph = Vph/Iph = 239.6/15 = 15.97 ohm

Step 2 — split the impedance

cos(phi) = 0.8 -> phi = 36.87 deg R = Z cos(phi) = 15.97 x 0.8 = 12.78 ohm X = Z sin(phi) = 15.97 x 0.6 = 9.58 ohm

Step 3 — total power

P = sqrt3 VL IL cos(phi) = 1.732 x 415 x 15 x 0.8 = 8625.6 W

Step 4 — the two wattmeter readings

Note how different the two readings are even at a reasonable power factor. That difference is what carries the reactive information.

W1 = VL IL cos(30 - phi) = 415 x 15 x cos(-6.87) = 6180.3 W W2 = VL IL cos(30 + phi) = 415 x 15 x cos(66.87) = 2445.3 W check: W1 + W2 = 8625.6 W - equals the total power check: tan(phi) = sqrt3 (W1-W2)/(W1+W2) -> phi = 36.87 deg which recovers the given power factor exactly
Answer
Vph = 239.6 V, R = 12.78 Ω, X = 9.58 Ω, P = 8625.6 W, W1 = 6180.3 W and W2 = 2445.3 W.
If the question comes in a different form
If the load is delta connected instead of star

The two relations swap over. In delta the phase voltage equals the line voltage, and the line current is √3 times the phase current. Using the star relation on a delta load is the standard way this question is lost.

star : V_ph = V_L/sqrt3 , I_ph = I_L delta : V_ph = V_L , I_ph = I_L/sqrt3 in both cases the total power is the same expression: P = sqrt3 V_L I_L cos(phi)
If the wattmeter readings are given and you must work backwards

The sum gives the power and the difference gives the angle. Oct 2024 gave P1 = 1580 W and P2 = 2150 W on a delta load and asked for everything else.

P = W1 + W2 tan(phi) = sqrt3 (W2 - W1)/(W1 + W2) Q = sqrt3 (W2 - W1) with 1580 and 2150 W: P = 3730 W , tan(phi) = 0.2647 , phi = 14.83 deg , pf = 0.967
If one wattmeter reads negative

That is not an error and it is worth saying so. When the power factor falls below 0.5 the angle exceeds 60°, cos(30 + φ) goes negative and the second wattmeter reads backwards. The total is still W1 + W2, with the negative sign included.

pf = 0.5 -> phi = 60 deg -> W2 = VL IL cos(90) = 0 pf < 0.5 -> phi > 60 deg -> W2 negative the meter has to be reversed to read it, and the reading subtracted
If it asks you to derive the line and phase relations

Show the phasor subtraction; quoting √3 without it gets about half. Two equal phasors 120° apart subtract to give one √3 times as long, leading by 30°.

V_RY = V_RN - V_YN = Vph /_0 - Vph /_-120 = Vph [(1 + j0) - (-0.5 - j0.866)] = Vph (1.5 + j0.866) = Vph x 1.732 /_30 so V_L = sqrt3 V_ph, leading the phase voltage by 30 degrees
Q67 marksTransformer

4 of 5 papers · 24 marks

Derive the EMF equation of a single-phase transformer. A 50 kVA transformer has 800 turns on the primary and 200 on the secondary, with the primary connected to a 3300 V, 50 Hz supply. Find the secondary voltage, the full-load current in each winding and the maximum flux in the core.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Any transformer numerical
  1. Write the turns ratio down first: a = N1/N2. Everything else follows from it.
  2. Voltages follow the ratio directly: V1/V2 = N1/N2.
  3. Currents follow it inversely: I1/I2 = N2/N1. This is the one people invert by mistake.
  4. Rated kVA does not change from one winding to the other — the same power passes through both. So each winding's full-load current is that one rating divided by that winding's own voltage.
  5. For flux, use the EMF equation rearranged: φm = V/(4.44 f N), using the turns of whichever winding's voltage you used.
  6. Check: I1V1 and I2V2 must both equal the rating, and E2 recomputed from 4.44 f N2φm must match the voltage you found.
Impedance referred across the transformer
  1. An impedance on the secondary side, seen from the primary, is multiplied by the square of the turns ratio: Z' = Z × (N1/N2)².
  2. Going the other way, divide by the square.
  3. The square is because voltage scales by a and current by 1/a, and impedance is their ratio.

Step 1 — the derivation, from Faraday

Start from a sinusoidal flux and differentiate. The √2 step is what separates a derivation from a quoted formula, and it is where the marks are.

phi = phi_m sin(wt) e = -N dphi/dt = -N w phi_m cos(wt) peak emf = N w phi_m = 2 pi f N phi_m rms = peak/sqrt2: E = 2 pi f N phi_m / sqrt2 = 4.44 f N phi_m

Step 2 — secondary voltage

V2 = V1 x N2/N1 = 3300 x 200/800 = 825 V

Step 3 — full-load currents

One rating serves both windings, so each full-load current is that rating over the voltage of its own winding.

I1 = S/V1 = 50 000/3300 = 15.15 A I2 = S/V2 = 50 000/825 = 60.61 A check: I1/I2 = 15.15/60.61 = 0.25 = N2/N1 - correct, the current ratio is the inverse of the turns ratio

Step 4 — maximum flux

Rearrange the equation you just derived.

phi_m = V1/(4.44 f N1) = 3300/(4.44 x 50 x 800) = 0.01858 Wb = 18.58 mWb check: E2 = 4.44 x 50 x 200 x 0.01858 = 825 V - matches step 2
Answer
E = 4.44 f N φm; V2 = 825 V, I1 = 15.15 A, I2 = 60.61 A, φm = 18.58 mWb.
If the question comes in a different form
If it asks for the phasor diagram on load

Follow that sequence when you draw, and name each phasor as you put it down — marks go to the labels, not to the neatness.

1. phi_m along the reference 2. E1 and E2 lagging phi_m by 90 degrees 3. I0, the no-load current: Iw in phase with V1 (core loss) Imag in phase with phi_m (magnetising) 4. I2 lagging E2 by the load angle 5. I2' = I2 x N2/N1, drawn opposite to I2 6. I1 = I0 + I2' (phasor sum) 7. V1 = -E1 + I1 R1 + j I1 X1 8. V2 = E2 - I2 R2 - j I2 X2
If it asks for the no-load diagram

Much simpler, because the secondary carries nothing. Only φm, E1, E2, I0 with its two components, and V1. Say that the no-load power factor is very poor — typically 0.1 to 0.2 — because almost all of I0 is magnetising current carrying no real power.

If the secondary voltage is given and the primary asked

Same ratio, run the other way. Oct 2024 gave a 1000 kVA transformer with 400/100 turns and E2 = 1000 V and asked for E1.

E1 = E2 x N1/N2 = 1000 x 400/100 = 4000 V I1 = S/E1 = 1 000 000/4000 = 250 A I2 = S/E2 = 1 000 000/1000 = 1000 A
If it asks about the principle of operation

Four sentences, and the last one is the mark most people miss: a transformer works on AC only, because a steady DC flux induces nothing. Say it explicitly.

1. AC on the primary sets up an alternating flux in the core 2. almost all of that flux links the secondary 3. that alternating flux links both coils and induces an emf in each, E = 4.44 f N phi_m, so the emfs follow the turns ratio 4. nothing rotates and nothing touches - energy crosses through the magnetic field alone, which is why DC will not work
Q75 marksMagnetic circuits

4 of 5 papers · 17 marks

An iron ring of mean length 1.2 m has an air gap of 1 mm cut in it and is wound with 400 turns. The relative permeability of the iron is 400. Find the flux density in the ring when a current of 3 A flows through the coil, and show how the mmf divides between the iron and the gap.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Any magnetic circuit
  1. Treat it exactly like a series electrical circuit: mmf is the driving voltage, flux is the current, and reluctance is the resistance. The same flux passes through every part in series.
  2. mmf = N I, in ampere-turns.
  3. For each section, H = B/μ where μ = μ0μr for iron and just μ0 for an air gap.
  4. The mmf divides between the sections: NI = H1l1 + H2l2 + …, with each l being that section's length along the path.
  5. The iron length is the mean path minus the gap, not the whole path.
  6. Solve for B, then flux Φ = BA if it is asked for.
  7. Check by adding the mmf of each section back up — it must return NI.
Unit traps worth writing on your hand
  1. Area: 1 cm² = 10−4 m². So 200 cm² is 0.02 m², not 2 m².
  2. For a circular section given by diameter, A = πd²/4.
  3. μ0 = 4π × 10−7 H/m. A permeability quoted as a bare number is always relative, whatever unit the paper attaches to it.

Step 1 — the same flux passes through both parts

Iron and air are in series magnetically, so the mmf divides between them in proportion to their reluctance. The whole point of this question is that a millimetre of air takes more mmf than a metre of iron.

mmf = N I = 400 x 3 = 1200 ampere-turns mmf = H_iron x l_iron + H_gap x l_gap = (B/(mu0 mu_r)) l_iron + (B/mu0) l_gap

Step 2 — solve for B

l_iron = 1.200 - 0.001 = 1.199 m l_gap = 0.001 m 1200 = (B/mu0) [ 1.199/400 + 0.001 ] = (B/mu0) [ 0.0029975 + 0.001 ] = (B/mu0) x 0.0039975 B = 1200 x 4 pi x 1e-7 / 0.0039975 = 0.3772 T

Step 3 — the split, which is the point of the question

iron : B/(mu0 mu_r) x 1.199 = 899.8 AT (75 %) gap : B/mu0 x 0.001 = 300.2 AT (25 %) ------- 1200.0 AT - checks out one millimetre of air, 0.08 % of the path, takes a quarter of the mmf
Answer
B ≈ 0.377 T, with about 900 AT across the iron and 300 AT across the 1 mm gap.
If the question comes in a different form
If a saw cut is made in a solid ring

The current stays the same, so the mmf stays the same — but now it has to push flux through air as well, and the flux collapses. Mar 2024 asked exactly this and the drop was about 86%.

solid ring, 600 turns, 0.8 m mean, mu_r = 1000, flux 0.5 mWb: I = 0.75 A now cut a 5 mm gap and keep the same current: flux falls to 0.069 mWb - about 14 % of what it was reason: the 5 mm of air is 0.6 % of the path but takes 86 % of the mmf
If you are given the flux and asked for the current

The same chain, run backwards. Start from B = Φ/A and finish at I = mmf/N. Watch the area conversion: 1 cm² = 10−4 m², so 200 cm² is 0.02 m², not 2 m².

phi -> B = phi/A -> H = B/(mu0 mu_r) -> mmf = H l -> I = mmf/N Mar 2026: 0.015 Wb across 200 cm2 over a 2.5 mm gap B = 0.015/0.02 = 0.75 T H = 0.75/(4 pi 1e-7) = 596 831 A/m mmf = 596 831 x 0.0025 = 1492 AT
If the permeability is quoted oddly

Oct 2024 said "permeability of iron 300 H/m". That is not physical — μ0 alone is 1.26 × 10−6 H/m. It has to mean relative permeability. State the assumption in one line and carry on; examiners accept it and it protects the marks.

If it asks about two coupled coils instead

Different topic under the same heading. There are two places M enters the sum — first as the influence coil 2 has on coil 1 and once the other way — which is where the factor of 2 comes from.

flux aiding : L_eq = L1 + L2 + 2M flux opposing : L_eq = L1 + L2 - 2M writing L1 + L2 +/- M is the standard error
Q83 marksDigital logic

1 of 5 papers · 9 marks

Simplify F = Σm(1, 3, 5, 7, 9, 11) using a Karnaugh map with input variables ABCD, and implement the result with logic gates.
How to do it — the method itself

The working below uses this paper’s numbers. These are the steps on their own, so you can follow them on any question of this type.

Karnaugh map simplification
  1. Draw the map with the rows and columns in Gray-code order — 00, 01, 11, 10. Never 00, 01, 10, 11.
  2. Put a 1 in every cell whose minterm is in the list and a 0 everywhere else.
  3. Before grouping, look at the whole map for a pattern. Often one variable is 1 in every listed minterm, and spotting that collapses the answer in one line.
  4. Group the 1s into rectangles of 1, 2, 4, 8 or 16 cells — powers of two only. Make each group as large as possible, and allow groups to overlap.
  5. Treat the map as though its edges were joined: cells at opposite ends of a row, or of a column, count as neighbours, so the four corners can form a single group of four.
  6. For each group, keep the variables that stay constant across it and drop the ones that change.
  7. OR the groups together. Then check your expression against every row of the truth table.
Two's complement arithmetic
  1. Write both numbers in the stated number of bits.
  2. To subtract, form the two's complement of the number being subtracted: invert every bit, then add one.
  3. Add the two numbers as ordinary binary.
  4. Discard any carry out of the most significant bit — when the operands had opposite signs the result cannot overflow, so the carry is simply dropped.
  5. If the leading bit of the result is 1 the answer is negative; take its two's complement back to read the magnitude.

Step 1 — plot in Gray-code order

The columns must run 00, 01, 11, 10 — not 00, 01, 10, 11. Gray order is what makes neighbouring cells differ by a single bit, which is the entire basis of the method.

CD=00 01 11 10 AB=00 0 1 1 0 AB=01 0 1 1 0 AB=11 0 0 0 0 AB=10 0 1 1 0

Step 2 — read the pattern before grouping

Every minterm listed has D = 1, and the only D = 1 cells missing are the AB = 11 row. Seeing that turns a four-term answer into a two-term one.

all of D = 1 except where A = 1 AND B = 1 F = D (A' + B') = A'D + B'D

Step 3 — the groups on the map

A'D covers 1, 3, 5, 7 (the top two rows, middle columns) B'D covers 1, 3, 9, 11 (wraps from the top row to the bottom row) two terms, four literals verified against all 16 input combinations - every row matches

Step 4 — the gates

Two inverters, two AND gates, one OR gate. Draw the inverters explicitly — using A' without showing where it comes from usually costs a mark.

A --[NOT]--+ +--[AND]--+ D ---------+ | +--[OR]--> F B --[NOT]--+ | +--[AND]--+ D ---------+
Answer
F = A'D + B'D — two AND gates into one OR gate.

If it asks for two's complement arithmetic

Invert every bit, add one, then add. The carry out of the sign bit is discarded when the two operands had opposite signs, because the result cannot overflow in that case.

(29) - (27) in 8-bit signed two's complement: +29 = 0001 1101 +27 = 0001 1011 1s comp = 1110 0100 2s comp = 1110 0101 = -27 0001 1101 + 1110 0101 = 1 0000 0010 drop the carry -> 0000 0010 = +2

Trace each gate back to the input lines before simplifying anything. Then look for a variable appearing both true and complemented with everything else the same — that variable drops out.

Then group normally, largest groups first, and remember the map wraps around in both directions — the top row touches the bottom row and the left column touches the right.

F = sum m(0,5,6,8,12,13): 0 and 8 -> B'C'D' (wraps top to bottom) 8 and 12 -> AC'D' 5 and 13 -> BC'D 6 alone -> A'BCD' F = A'BCD' + B'C'D' + BC'D + AC'D' - 13 literals
The check that takes thirty seconds

Evaluate your simplified expression for every minterm in the list and for a couple that are not in it. With four variables there are only sixteen rows, and a simplification that is subtly wrong shows up immediately.
